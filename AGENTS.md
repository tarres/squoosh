# AGENTS.md

Squoosh: client-side image compression web app (Preact + TypeScript + Rollup + Web Workers via comlink). Legacy Google project, low-maintenance, minimal deps.

## Commands

- `npm install` → then `npm run build` (`rollup -c && node lib/move-output.js`). Rollup internally shells out to `tsc -b` (see `lib/simple-ts.js`), so `build` is effectively typecheck+bundle.
- `npm run dev` → `run-p watch serve`, serves `.tmp/build/static` on `DEV_PORT` (default 5000) via `serve`. Must `npm run build` first. Note: the `serve` script's `--config ../../../serve.json` is a stale/broken relative path (resolves to nothing from project root) — don't rely on COOP/COEP headers from it in dev.
- No standalone `typecheck`/`test`/`lint` scripts. `npm run build` is the only verification gate; CI (.github/workflows/node.js.yml) runs `npm ci && npm run build`.
- Formatting: `lint-staged` (husky) runs prettier / clang-format / rustfmt on commit. Prettier: single quotes, trailing commas (`.prettierrc.json`).

## Build plumbing (non-obvious)

- No standard TS-bundler. `lib/simple-ts.js` runs `tsc -b` into `.tmp/ts`, then Rollup loads the emitted JS directly. Rollup's watch excludes `**/*.ts` and watches the `.tmp/ts` output instead.
- Build output: `.tmp/build/static`, then `lib/move-output.js` renames it to `build/`. Both `.tmp` and `build` are gitignored.
- **Generated files — never edit, they're gitignored and regenerated by `lib/feature-plugin.js` on every build:**
  - `src/features-worker/index.ts`
  - `src/client/lazy-app/worker-bridge/meta.ts`
  - `src/client/lazy-app/feature-meta/index.ts`
  - `*.scss.d.ts` / `*.css.d.ts`
- Worker/client comlink wiring is auto-derived from file structure (see Features).

## Features architecture

`src/features/{encoders,decoders,processors,preprocessors}/<name>/{client,worker,shared}/`.

- `client/` → client project, `worker/` → worker project, `shared/` → both.
- Every `.ts` file in a feature's `worker/` becomes an auto-exposed comlink method named after the file (default export). Adding one regenerates the wiring — add the file, rebuild, don't touch generated refs.
- Encoders must export `shared/meta.ts` (`label`, `mimeType`, `extension`, `EncodeOptions`, `defaultOptions`) and `client/index.ts` (`encode(AbortSignal, WorkerBridge, ImageData, EncodeOptions)` → `ArrayBuffer`). Full contract in `src/features/README.md`.
- Import path aliases (from `generic-tsconfig.json`): `static-build/*`, `client/*`, `shared/*`, `features/*`, `worker-shared/*`.

## Codecs (WASM)

`codecs/` is a set of self-contained emscripten/rust sub-projects (avif, jxl, webp, mozjpeg, oxipng, etc.). Built separately via Docker (`codecs/README.md`); each emits `<name>_<enc|dec>.js` + `.wasm` exposing a global Emscripten `Module`. Not part of the main `npm run build`. Built outputs shipped in-repo for the app to consume.

## Gotchas

- **No `new URL(..., import.meta.url)`** anywhere reachable from the static build — it throws a hard error (see `resolveImportMetaUrlInStaticBuild` in `rollup.config.js`).
- Node version pinned to `20.16.0` (`.nvmrc`).
- `lib/*.js` build plugins are handwritten Rollup plugins in plain JS (not TS) — keep them working with the existing plugin architecture.
